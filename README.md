# Portal Intracom — Home

Página única autocontenida (`index.html`): tipografías, imágenes y scripts van incrustados.

## Publicar en GitHub Pages
1. Sube `index.html` a la raíz del repositorio.
2. Settings → Pages → Source: `main` / root.
3. La web queda en `https://<usuario>.github.io/<repo>/`.

Nota: las fotos de MediaEthics (Florianópolis) y Gendercom (Alhambra) se cargan desde Wikimedia Commons; la de Florianópolis requiere atribución (CC BY 2.0).
